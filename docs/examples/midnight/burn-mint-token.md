# Burn & Mint Token

This guide is under development.

The pattern: your Midnight-native token burns on Midnight when it leaves, and the destination chain mints it. Total supply across chains stays constant.

Want to build this now? [Work with us](/docs/work-with-us/developers), or read [Integration Paths](/docs/examples/midnight/integration-paths) to prepare.
