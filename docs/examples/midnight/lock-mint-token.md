# Lock & Mint Token

This guide is under development.

The pattern: a token that lives on another chain locks at its home contract, and your contract mints it on Midnight. USDM runs this pattern today — locked on Cardano, minted on Midnight. You can bridge it right now with the [USDM bridge guide](/docs/examples/guides/usdm-cardano-midnight).

Want to build this now? [Work with us](/docs/work-with-us/developers), or read [Integration Paths](/docs/examples/midnight/integration-paths) to prepare.
